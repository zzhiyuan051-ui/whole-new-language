# 洄文范文

四篇范文，每篇 `.hw` 是**源**（线性形式，人工可读、机器可解），
同名的 `.svg` 是**关系图**（洄文的正体：把图铺到纸面上），`.png` 是预览。

生成与校验（一条命令同时做两件事）：

```powershell
python ../tools/hwrender.py 01_yyna.hw --title "洄文范文一 · 雨夜"
```

## 篇目

| 文件 | 题 | 演示什么 |
|---|---|---|
| `01_yyna.hw` | **雨夜** | 临弓填槽（甲/戊/己/乙）、饰弓限定、否定模态 `~`、三种义标 |
| `02_gu2.hw` | **忘** | 饰弓作「之」、甲位与庚位之别、同词根不同接法 |
| `03_ybiao.hw` | **三种义标** | 同一件事用「亲见／传闻／想象」说出：合法性相同、可信度不同 |
| `04_wenda.hw` | **问答** | 结际弓、**子图整体当端点**（方括号跨行书写） |

## 源文的写法（速记）

```
.graph <这一句的标题>      // 一句 = 一张图

@0 yy4.体                 // 结声明：@标号 词根.换声（体/貌/用/度/场）
@1 pe2.用
@1 -> 0                   // 临弓：按槽表顺序填位（这里填甲位）
@1 -戊-> 2                // 临弓：显式指定位（戊位 = 处所/时间）
@3 ya2.貌
@3 => 2                   // 饰弓：修饰语 → 被修饰者（即「之」）
[ ... ] -庚-> @1          // 子图整体当端点（方括号可跨行写）
~  ?  !                   // 模态：否定 / 疑问 / 祈使（罩住整图）
#see #hear #felt #infer #hearsay #common #imagine #dream   // 义标（必具）
```

## 音节用哪一批

范文里出现的词根音节属于**前 16 场**（调 1–4），虚词属于**调 6**：

| 用途 | 音节示例 |
|---|---|
| 词根（前 16 场） | `yy4` 雨、`pe2` 落、`po4` 夜、`ye4` 地、`gy2` 回忆 |
| 虚词（调 6） | `yi6` 我、`yo6` 你、`yoe6` 他、`sa6` 此、`le6` 毋 |
| 派生词（双音节） | `yy4 ni5` 雨具、`pe4 sy5` 月之时 |

> 音节分配见 `../spec/03-phonology.md`：**按调分组**，每加一个调只为新场次服务，
> 旧词读音一个字节不改。

## 校验

`hwrender.py` 会把违反七条设计律的地方当场列出来——临位没填满、结接不到主结上、
缺义标、词根不在词表里。校验不通过不抛异常，只把事实摆出来，照着改即可。
四篇范文（10 图 38 弓）在 `../tools/hwselftest.py` 里每次全链路自检都会重跑一遍。

# 第三编　写字

> 汉字的难处在于**要一个个记**。洄文没有这个负担：
> **字形是算出来的**。给一个编号，按四条规则走一遍，字就出来了。
> 全部一万五千个字，用的是同四条规则。

---

## 第 7 课　字形是算出来的：编号 → 字形

### 7.1　先看四个字，找找规律

| 编号 | 字形 | 词 |
|---:|---|---|
| 0 | 方框 ＋ 正中一点 | `ba` 现实 |
| 1 | 圆框 ＋ 正中一点 | `da` 序 |
| 2 | 菱框 ＋ 正中一点 | … |
| 3 | 方框 ＋ 正中一点 ＋ 左下一点 | … |

看出两件事了吗：

1. **框的形状在循环**：方、圆、菱、方、圆、菱……
2. **框里除了正中，还会多出零零星星的点与线**

这两件事都不是随意的。第 1 件是**校验**（下一节讲），
第 2 件是**编号**（本节讲）。

### 7.2　字格：一个字的「房间」

每个字住在一个 **4 列 × 5 行**的格子里。正中间那一格**永远留给「类标记」**，
其余 12 格里有 8 格是「数字位」。

```
　　　┌────┬────┬────┬────┐
　　　│ 位1│ 位2│ 位11│ 位3│　　← 位11 暂空
　　　├────┼────┼────┼────┤
　　　│　　│ 位7│　　│ 位8│
　　　├────┼────┼────┼────┤
　　　│ 位9│　　│类标│　　│　　← 位9 暂空；中央格是类标记
　　　├────┼────┼────┼────┤
　　　│　　│ 位10│ 位12│　　│　　← 位10、位12 暂空
　　　├────┼────┼────┼────┤
　　　│ 位6│ 位5│　　│ 位4│
　　　└────┴────┴────┴────┘
```

**要记的只有 8 个位**（位1 到 位8），另外 4 格是留给将来扩充的。

### 7.3　每个位可以落四种「笔」

| 值 | 笔 | 画法 |
|---:|---|---|
| **0** | 空 | 这一位不落笔 |
| **1** | 点 | 画一个小点 |
| **2** | 横 | 画一道短横（在**角落**的位上改画斜线） |
| **3** | 环 | 画一个小圆圈 |

> **位1 和 位2 要用「双笔」**：双点、双横、双环。
> 这是为了让字的**重心**压在左上，看起来稳。其余六位一律单笔。

### 7.4　算式：编号换成八位四进制

编号是一个普通的整数。把它写成**四进制**（逢四进一），取八位，就得到八个位的值：

```
　　编号 137
　　137 ÷ 4 ＝ 34 余 1　　→ 位8 ＝ 1（最轻）
　　 34 ÷ 4 ＝  8 余 2　　→ 位7 ＝ 2
　　  8 ÷ 4 ＝  2 余 0　　→ 位6 ＝ 0
　　  2 ÷ 4 ＝  0 余 2　　→ 位5 ＝ 2
　　　　　　　　　　　　　→ 位4、位3、位2、位1 都是 0（高位补零）
```

于是字形是：**位5 画一道横，位7 画一道横，位8 画一个点**，其余留空。

**不会算除法也没关系**：查现成的字表（`charts/`），
或者记住「从右往左，四个一进位」就够了。

### 7.5　每个位在字的哪个地方

这是唯一需要背的一张表——只有八行：

| 位 | 位置 | 权重（4 的几次方） |
|---:|---|---|
| 位1 | 左上 | 4⁷ ＝ 16384 |
| 位2 | 上排左二 | 4⁶ ＝ 4096 |
| 位3 | 右上 | 4⁵ ＝ 1024 |
| 位4 | 右下 | 4⁴ ＝ 256 |
| 位5 | 下排中 | 4³ ＝ 64 |
| 位6 | 左下 | 4² ＝ 16 |
| 位7 | 上排右二 | 4¹ ＝ 4 |
| 位8 | 右中 | 4⁰ ＝ 1 |

> 注意位7 和位8 的权重最小（4 和 1），因为它们是**最后启用的两位**。

### 7.6　练习

1. 编号 0 的字是什么样子的？（八个位的值都是 0）
2. 编号 4 的字：位8 的权重是 1，4 ÷ 4 ＝ 1 余 0，所以位7 ＝ 1。画出这个字。
3. 编号 5 呢？（5 ＝ 4×1 ＋ 1，所以位7 ＝ 1、位8 ＝ 1）
4. 判断：编号越大，字一定越复杂吗？

### 7.7　答案

1. **只有边框和中央的类标记，八个位全空**——就是第 7.1 节表里编号 0 的样子。
2. 位7 ＝ 1（一个点，在**上排右二**的位置），其余全空。
3. 位7 ＝ 1 与位8 ＝ 1：上排右二一个点，**右中**一个点。
4. **大致如此，但不绝对**。编号大意味着四进制位数多，落笔的位通常更多；
   但如果高位是 0（比如编号 15 与编号 16 相比），也可能反而简单。

## 第 8 课　边框是校验码：抄错一笔自己知道

### 8.1　框有四种？其实是三种

数一数第 7.1 节的表：方框、圆框、菱框、方框、圆框、菱框……
**只有三种**，按顺序循环。

### 8.2　边框怎么定的

```
　　边框 = 编号 ÷ 3 的余数
　　　　余 0 → 方框　　余 1 → 圆框　　余 2 → 菱框
```

验证一下：

```
　编号 0　0 ÷ 3 余 0　→　方框　✓（表里是方框）
　编号 1　1 ÷ 3 余 1　→　圆框　✓（表里是圆框）
　编号 2　2 ÷ 3 余 2　→　菱框　✓
　编号 3　3 ÷ 3 余 0　→　方框　✓（表里是方框）
```

### 8.3　为什么这一条很有用

因为它让你能**自己检查自己有没有抄错**：

```
　　1. 把字里八个位的值加起来
　　2. 除以 3，看余数
　　3. 余数应当与边框相符（余 0 方、余 1 圆、余 2 菱）
```

**为什么成立**（可以跳过，不影响使用）：四进制的每一位权重都是 4 的幂，
而 4 除以 3 余 1，所以 4 的任何次方除以 3 都余 1。
于是「编号除以 3 的余数」就等于「八个位的值相加再除以 3 的余数」。
这条性质叫「模 3 不变」，是洄文字形能自校验的根据。

### 8.4　一个实例

```
　　编号 137：位5 ＝ 2（横），位7 ＝ 2（横），位8 ＝ 1（点）
　　八位之和 ＝ 2 ＋ 2 ＋ 1 ＝ 5
　　5 ÷ 3 余 2　→　应当是菱框
　　而 137 ÷ 3 ＝ 45 余 2　✓　一致
```

### 8.5　练习

1. 编号 6 的字，边框是什么形状？
2. 你抄了一个字，八个位的值是 3、1、0、0、2、0、1、0，边框画成了圆形。
   检查一下：抄对了吗？
3. 如果八位之和是 9，边框应当是什么？

### 8.6　答案

1. 6 ÷ 3 余 0 → **方框**。
2. 和 ＝ 3＋1＋0＋0＋2＋0＋1＋0 ＝ 7，7 ÷ 3 余 1 → 应当是**圆框**。抄对了。
3. 9 ÷ 3 余 0 → **方框**。

## 第 9 课　中央格告诉你它谈什么

### 9.1　中央格里画的是什么

中央格不参与编号，它画的是**这个字属于哪一类意思**。
洄文把全部词分成 **44 个语义类**，每一类有一个固定的中央标记。

### 9.2　先认最常用的十个

| 类 | 中央标记 | 这个类谈什么 | 例词 |
|---|---|---|---|
| 本体 | 一点 | 存在、同异、因果 | `ba` 现实 |
| 数量 | 双点 | 数、多少、比较 | `da` 序 |
| 空间 | 三点 | 方位、形状、边界 | `ga` 侧 |
| 时间 | 四点 | 先后、久暂、周期 | `sa` 时间 |
| 运动 | 单环 | 来去、推拉、升降 | `la` 移动 |
| 身体 | 双环 | 身体、五感、生死 | `bi2` 眼 |
| 心灵 | 药丸 | 情绪、记忆、意志 | `goe2` 记忆 |
| 社会 | 尖角 | 亲属、权力、礼俗 | `na2` 家 |
| 信息 | 三角 | 语言、问答、教与学 | `pa3` 语言 |
| 自然 | 波纹 | 天地水火、草木鸟兽 | `yy4` 雨 |

> **一眼看去就知道这段文字在谈什么**——这是中央格的全部作用。
> 你不必读懂任何数字位，就能知道这个词属于哪一大类。

### 9.3　44 类是怎么容纳的

44 类，但中央标记只有 **20 种**，是循环使用的：
类号除以 20 的余数，决定用哪一种标记。

```
　　类 0（本体）　用第 0 种标记（一点）
　　类 20（医药）　用第 0 种标记（一点）——与本体同类标记
　　类 40（商易）　用第 0 种标记（一点）
```

同标记的两类分属不同大族，配合**边框**与**数字位**仍然分得开。
完整 44 类表见 `spec/01-script.md`。

### 9.4　练习

1. 看到一个字的中央格画的是**波纹**，这个字大概在谈什么？
2. 中央格画的是**双环**，呢？
3. 中央标记一共有多少种？语义类一共有多少个？

### 9.5　答案

1. **自然类**——天地、水火、草木、鸟兽这一路。
2. **身体类**——身体部位、五感、生死。
3. 标记 **20 种**，语义类 **44 个**（标记循环使用）。

## 第 10 课　换声记号：同一个词的几副面孔

### 10.1　同一个词，可以当名词也可以当动词

前面说过洄文的词**没有固定词性**。那么字形上怎么表示它这次是当什么用？
答案：**在字的外面加一个小记号**。

### 10.2　五种记号

| 记号 | 名 | 用在 | 画在哪 |
|---|---|---|---|
| （无） | **体** | 指事物本身 | 不加 |
| 一点 | **貌** | 指「……的」 | 正上方 |
| 一竖 | **用** | 指「做……」 | 正下方 |
| 双点 | **度** | 指「……地」（程度方式） | 右侧 |
| 一横 | **场** | 指「……之处／之时」 | 左侧 |

```
　　　　 ·　　　　　　　　　　　　　　　　∶
　　　┌─────┐　　　　　┌─────┐　　　　┌─────┐
　　　│　字形 │　　　　　│　字形 │　　　　│　字形 │
　　　└─────┘　　　　　└─────┘　　　　└─────┘
　　　　 │　　　　　　　　　　　　　　　　（体：什么都不加）
　　　　（用）　　　　　　　（体）　　　　　　（度）
```

### 10.3　一个例子看五种面孔

以「雨」为例：

| 换声 | 写法 | 意思 |
|---|---|---|
| **体** | `yy4.体` | 雨（作为一种东西） |
| **貌** | `yy4.貌` | 下雨的、雨的 |
| **用** | `yy4.用` | 下雨（这件事、这个动作） |
| **度** | `yy4.度` | 雨一般地（方式） |
| **场** | `yy4.场` | 雨落之处或之时 |

**注意：换声不造新词。** 五种面孔用的还是同一个音节、同一个字形，
只是外面多了一个小记号。

### 10.4　记号可以省

在句子里，如果**位置已经说明了它扮演什么**，记号可以省掉。
比如在图里，「雨─甲位→落」这样的连线已经表明「雨」在当施事，
这时不写 `.体` 也不会误会。

> 但对初学者，**建议每次都写全**。写着写着就熟了，再省不迟。

### 10.5　练习

1. 「看」要当动作使，换声记号画在字的哪一边？
2. 「慢慢地」里的「慢」，用哪一种换声？
3. 判断对错：`yy4.貌` 和 `yy4.用` 是两个不同的词。
4. 若要把「水」当「水的」（如「水的冷」），用哪种换声？

### 10.6　答案

1. **正下方**（一竖，即「用」）。
2. **度**（双点，画在右侧）——「慢」当程度方式用。
3. **错**。它们是**同一个词**的五副面孔之一，只是立场不同；音节与字形基底都一样。
4. **貌**（一点，画在正上方）。

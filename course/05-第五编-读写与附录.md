## 第 19 课　读范文《雨夜》

### 19.1　原文

这是洄文的范文之一（`texts/01_yyna.hw` 的第一句）：

```
　　@0 yy4.体　　　　雨
　　@1 pe2.用　　　　落
　　@2 po4.体　　　　夜
　　@3 ya2.貌　　　　静
　　@4 ye4.体　　　　地
　　@1 -甲-> 0　　　 落，其主体是雨
　　@1 -戊-> 2　　　 落，其时间是夜
　　@1 -己-> 4　　　 落，其归向是地
　　@3 => 2　　　　　静，限定夜
　　#see　　　　　　　义标：亲见
```

### 19.2　一步一步读

**第一步：找主结。**
哪一个是主结？看哪一条弓都不指向它、而它指向别人——是 `@1 落`。
所以这句话是**在说「落」**。

**第二步：看它有几个槽要填。**
`pe2` 落的槽表是 **甲 戊 己**，三个位。

**第三步：看每条弓填的是哪一位。**

```
　　@1 -甲-> 0　　落的主体是雨　　→　是「雨」在落
　　@1 -戊-> 2　　落的时间是夜　　→　落在夜里发生
　　@1 -己-> 4　　落的归向是地　　→　落向地面
```

**第四步：看饰弓在限定什么。**

```
　　@3 => 2　　静（当作性质）限定夜　→　「静之夜」
```

**第五步：看义标。**

```
　　#see　→　这是说话人亲眼看见的
```

**第六步：合成汉语。**

> **我看见雨落在地上，在静静的夜里。**

### 19.3　读的时候要防的三个坑

| 坑 | 说明 |
|---|---|
| **箭头方向搞反** | 临弓是「谓语 → 论元」。看到 `@1 -甲-> 0`，是「落要的主体是雨」，**不是**「雨做落」 |
| **把饰弓当成临弓** | `=>` 是限定，`->` 是填槽。两个方向相反 |
| **忘了义标** | 读的时候一定要问：这句是亲见、传闻，还是想象？意思会不一样 |

### 19.4　接下去的两句

范文的第二、三句：

```
　　第二句　@0 tu2.体　@1 si6.体　@2 lv.用　@2 -甲-> 0　@1 -乙-> 0　~　#felt
　　第三句　@0 gy2.用　@1 si6.体　@2 pe4.体　@0 -甲-> 1　@0 -庚-> 2　#see
```

自己试着读：

1. 第二句里 `~` 表示什么？（第 13 课提过：`~` 是否定模态，罩住整图）
2. 第二句的义标是 `#felt`（亲身感受），为什么用这个而不是 `#see`？
3. 第三句说的是什么？

### 19.5　答案

1. `~` 是**否定**——「停」这件事没有发生，即「不能睡」。
2. 因为「不能睡」是**自己身上感到**的，不是看见的。
3. `gy2` 回忆，槽表 甲庚：主体是我（甲），内容是月（庚）。
   整句是「**我忆月**」——义标 `#see`（亲见）。

## 第 20 课　自己写一段

### 20.1　写作的六步

每次写洄文，都按这六步走，不会乱：

```
　1. 想清楚这句话「在说哪件事」——那就是主结
　2. 查主结的槽表，看它要几个位
　3. 把要填进去的词都写成结（各给一个标号）
　4. 一条一条画临弓（建议写明位名：-甲-> -乙-> …）
　5. 要限定的，用饰弓（=>）；要指前面的，用回指（..）
　6. 最后写义标（#see / #hearsay / #felt …）
```

**第 4 步和第 6 步最容易被初学者漏掉**。漏了第 4 步句子不闭合；
漏了第 6 步句子不合法。

### 20.2　动手写：把汉语译成洄文

**练习一**：我看见月亮在河里。

用到的词：`si6` 我／`doe2` 看（槽表 甲庚）／`pe4` 月／`py4` 河

先想：**主结是什么？**是「看」。它要甲位（谁看）和庚位（看什么）。
「月亮在河里」是看的内容——所以要把它做成**子图**。

```
　　@0 doe2.用　　　　看
　　@1 si6.体　　　　 我
　　@0 -甲-> 1　　　　看，其主体是我
　　[ @2 pe4.体　@3 py4.体　@2 -戊-> 3 ]　-庚->　@0
　　　　（子图：月在河）——整体当作「看」的内容
　　#see
```

> 汉译回读：**我看见「月在河里」**。

**练习二**：听说明天要下雨，所以我带伞。

提示：洄文**没有「伞」这个词**（词表里没有）。按洄文的规矩，
可以说「雨具」（`yy4 ni5`，用于雨的器具）。

```
　　[ @0 yy4.体　@1 pe2.用　@1 -甲-> 0 ]　+>　@2
　　　　（子图：雨落）——是下面那件事的原因
　　@2 le.用　　　　　 带（携）
　　@3 si6.体　　　　　我
　　@4 yy4 ni5.体　　　雨具
　　@2 -甲-> 3
　　@2 -乙-> 4
　　#hearsay
```

> 汉译回读：**因为（听说要）下雨，所以我带雨具**。

### 20.3　动手指：把这个字画出来

字形编号 **137** 的字。按第 7 课的算法：

```
　137 ÷ 4 ＝ 34 余 1　→ 位8 ＝ 1（右中，一个点）
　 34 ÷ 4 ＝  8 余 2　→ 位7 ＝ 2（上排右二，一道横）
　  8 ÷ 4 ＝  2 余 0　→ 位6 ＝ 0（左下，空）
　  2 ÷ 4 ＝  0 余 2　→ 位5 ＝ 2（下排中，一道横）
　其余位1–位4 都是 0（空）
　边框：137 ÷ 3 余 2 → 菱框
```

于是：**菱框；下排中一道横；上排右二一道横；右中一个点**。
再按第 8 课自查一遍：

```
　八个位的和 ＝ 1＋2＋2 ＝ 5　→　5 ÷ 3 余 2　→　应当是菱框　✓
```

画对了。

### 20.4　最后一段话

学到这里，你已经掌握了洄文的全部规则：

- **发音**：13 声基、8 腔、6 调
- **写字**：八个数位、边框校验、44 类标记、五种换声
- **说话**：结、七临位、三种弓、义标、子图
- **造词**：20 个派生式

剩下的只有**词汇量**。附录乙列了最常用的 300 个词，
足以表达日常的绝大部分意思；其余的词在《洄文字典》里。

> 记住这门语言的那句话：
> **一句话是一张图。说话是把图搭起来，听懂是在图上走通。**
> 而**写错一个字不算错，把「听说」说成「亲见」才是错**。

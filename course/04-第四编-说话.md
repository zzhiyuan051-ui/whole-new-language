# 第四编　说话

> 这一编是全书的核心。学会了它，你就能读懂任何一句洄文，也能自己写。
> 十八条规则不多，但**每一条都要动手画图**。
> 学每一课时都问自己同一个问题：**「这条线是从谁画到谁的？」**

---

## 第 11 课　结：词不能单独成句

### 11.1　汉语的一个字也能成句

汉语里说「好！」，一个字就是一个句子；说「谁？」，也是一个句子。
**洄文不能这样。**

洄文的词都是**不自由**的：它必须进入至少一条弓，才能成为句子的一部分。
单独摆一个词，那不算句子，只算**摆了一个结**。

### 11.2　「结」是什么

「结」就是图上的一个点，一个词占一个结。一句话里的每个词，都是一个结。

```
　　　　〔我〕　　　　〔吃〕　　　　〔饭〕
　　　　 结1　　　　　结2　　　　　结3
```

三个结摆好了，但这**还不是句子**。要连上线才是。

### 11.3　一张图只能有一个「主结」

一副图里，有一个结是**出发点**，叫「**主结**」。其余所有结，都要能沿着线走到主结。
走不到的结叫**孤结**，句子就不成立。

```
　　　　〔我〕
　　　　　│
　　　　　│
　　　　〔吃〕
　　　　　│
　　　　　│
　　　　〔饭〕
```

这张图里，「吃」是主结，「我」和「饭」都连着它，所以句子成立。

### 11.4　已写下的结才可以被连

**一条弓的两端，必须都是已经写出来的结。**
不能先画线，再补点。所以写洄文时，顺序是：

```
　　1. 先把该用的结都写出来（每个结给一个标号）
　　2. 再一条一条地画弓
```

> 这条规矩还有个副效果：**图上不会出现绕回来的圈**。
> 要指「自己」，用「回指弓」（第 18 课），不是画个圈。

### 11.5　怎么写下来

纸面上当然可以画图。但在纸上写长文时，人们用一种**线性写法**（也叫「源文」），
一行一件事，方便抄写与校对：

```
　　@0 yy4.体　　　　← 结 0：雨，当作事物
　　@1 pe2.用　　　　← 结 1：落，当作动作
　　@1 -> 0　　　　　 ← 画一条弓：从「落」到「雨」
　　#see　　　　　　　← 义标：亲见
```

- `@` 后面是**标号**，给每个结起个名字
- `.体`、`.用` 是**换声**（第 15 课）
- `->` 是**临弓**（第 13 课）
- `#see` 是**义标**（第 16 课）

### 11.6　练习

1. 「词不能单独成句」——那么单独写一个 `yy4.体`，算句子吗？
2. 一副图里有几个主结？
3. 下面这张图为什么不成立？

```
　　　　〔我〕　　　　〔雨〕
　　　　　│
　　　　〔看〕
```

4. 写洄文时，为什么必须先把结写完，再画线？

### 11.7　答案

1. **不算**。它只是一个结，没有进入任何弓，句子不闭合。
2. **有且只有一个**。
3. 因为「雨」这个结没连上任何线，是**孤结**——走不到主结「看」上。
4. 因为一条弓的两端必须都是**已经写出来的**结；先画线就无处可连。

## 第 12 课　七临位：每个词自带一张「待填的表」

### 12.1　最要紧的一句话

汉语的词有词性：名词、动词、形容词。**洄文的词没有词性。**
那怎么知道一个词该怎么用？看它**自带的那张表**。

每个词都带一张表，写着「我需要几个位，分别是什么位」。
这张表叫「**槽表**」，表上的格子叫「**临位**」。

### 12.2　七位各是什么

一共七位，用天干的头七个字命名：

| 位 | 名 | 什么意思 | 汉语里大致是 |
|---|---|---|---|
| **甲** | 施事 | 做这件事的是谁 | 主语 |
| **乙** | 受事 | 做的是什么、被作用的是谁 | 宾语 |
| **丙** | 予事 | 给谁、对谁、为谁 | 双宾语里的「谁」 |
| **丁** | 工具 | 用什么做的 | 「用……」 |
| **戊** | 处所／时间 | 在哪里、什么时候 | 「在……」 |
| **己** | 因由 | 因为什么、往哪里 | 「因为……」「朝……」 |
| **庚** | 语题 | 说了什么、想了什么 | 引语 |

**七位不是七个格，是七个空位。** 每个词需要哪几个位，是它自己的事。

### 12.3　槽表长什么样

| 词 | 槽表 | 意思 |
|---|---|---|
| `yy4` 雨 | **乙** | 雨是个事物，只需要一个受事位 |
| `pe2` 落 | **甲 戊 己** | 落需要有主体（甲）、时间地点（戊）、归向（己） |
| `poe2` 递 | **甲 丙 乙** | 递需要有主体（甲）、给谁（丙）、递什么（乙） |
| `gy2` 回忆 | **甲 庚** | 回忆需要有主体（甲）、回忆的内容（庚） |
| `si6` 我 | （虚词，无槽） | 代词不需要槽 |

> **好消息**：槽表不用一个个背。它由词的**意思类型**推出来：
> 是事物的就带乙位，是动作的就带甲乙，是给予类的就带甲丙乙……
> 规则写在 `tools/valence.py`，全书 3000 个词的槽表都是这样推出来的。

### 12.4　槽填不满，句子不闭合

一张图里，**每个该填的槽都必须填上**。少填一个，这张图就不闭合，
句子不成立。这条规矩叫「**临位必满**」。

```
　　　　〔落〕　　　　　　← 落需要 甲、戊、己 三个位
　　　　　│
　　　　〔雨〕　　　　　　← 只填了甲位（雨落）
　　　　　　　　　　　　　 戊位、己位空着 → 句子不闭合
```

要让它成立，得把戊位（什么时候）和己位（落到哪里）也填上。

> 多填的位**不算错**，算「附带说明」。但少填一定不成立。

### 12.5　练习

1. 「雨」的槽表是什么？为什么它不需要甲位？
2. 「递」需要哪三个位？分别填什么？
3. 判断：`pe2.用`（落）只接了甲位，句子成立吗？
4. 「回忆」的庚位填什么？

### 12.6　答案

1. **乙位**。因为雨是**事物**——它是被作用的、被谈论的，不是做事的。
2. **甲、丙、乙**：甲是递的人，丙是递给谁，乙是递的东西。
3. **不成立**。落需要甲、戊、己三个位，只填一个就不闭合。
4. 回忆的**内容**——你回忆起的那件事、那个人。

## 第 13 课　临弓：把槽填满

### 13.1　临弓的方向

**临弓**是「填槽」的弓。它的方向是：

```
　　　　谓语　──临弓──▶　论元
```

**从需要填槽的那个词，画向被填进去的那个词。**
箭头指向被填进去的那个词——这一点务必记牢，**洄文的箭头和汉语的语序方向相反**。

### 13.2　怎么看出一条临弓填的是哪一位

有两种写法：

| 写法 | 意思 |
|---|---|
| `@1 -> @0` | **按槽表顺序**填——第一个槽填甲位，第二个槽填乙位…… |
| `@1 -戊-> @2` | **指名道姓**地填戊位 |

初学时建议**每次都写明**（`-甲->`、`-乙->`……），不容易错。

### 13.3　一个完整的例子

「我看见雨落在地上，在夜里」：

```
　　@0 yy4.体　　　　雨
　　@1 pe2.用　　　　落
　　@2 po4.体　　　　夜
　　@3 ye4.体　　　　地
　　@1 -甲->  0　　　 落，其主体是雨
　　@1 -戊->  2　　　 落，其时间是夜
　　@1 -己->  3　　　 落，其归向是地
　　#see　　　　　　　义标：亲见
```

画成图：

```
　　　　　〔雨〕　　　　〔夜〕　　　　〔地〕
　　　　　　▲　　　　　　▲　　　　　　▲
　　　　　　│甲　　　　　│戊　　　　　│己
　　　　　　└─────┐　　│　　　┌───┘
　　　　　　　　　　│　　│　　　│
　　　　　　　　　〔落〕──┘　　　│
　　　　　　　　　　└────────┘
```

**「落」是主结**，三条弓都从它出发，分别指向三个论元。

### 13.4　没写位名时，怎么判断填的是哪一位

**按槽表顺序**。以「落」（槽表 甲戊己）为例：

```
　　第一条临弓 → 甲位
　　第二条临弓 → 戊位
　　第三条临弓 → 己位
```

如果超出的槽表（第四条、第五条……），一律当乙位，算附带说明。

### 13.5　练习

1. 把「我吃饭」写成洄文（`si6` 我、`sa4` 吃、`lv2` 食物）。
2. `@0 poe2.用　@1 si6.体　@2 so4.体　@3 yi3.体` 加上 `@0 -甲-> 1`、`@0 -丙-> 2`、`@0 -乙-> 3`，
   说的是什么事？
3. 一条临弓的箭头指向**被填的**那个词，还是指向**填槽的**那个词？
4. 「落」的第一条临弓（没写位名）填的是哪一位？

### 13.6　答案

1. ```
　　@0 sa4.用　@1 si6.体　@2 lv2.体
　　@0 -甲-> 1
　　@0 -乙-> 2
　　#see
　　```
   即：吃，其主体是我；吃，其客体是食物。
2. 「我把礼物递给你」——递的主体是我（甲），递给的是你（丙），递的是礼物（乙）。
3. 指向**被填进去的那个词**（论元）。方向是「谓语 → 论元」。
4. **甲位**（槽表的第一位）。

## 第 14 课　饰弓：相当于汉语的「之」

### 14.1　汉语的「之」和「的」

汉语「雨**的**夜」里，「雨」限定「夜」。洄文用**饰弓**表达：

```
　　　　修饰语　──饰弓──▶　被修饰者
```

**注意方向**：饰弓是从**修饰语**画向**被修饰者**，
与临弓（谓语 → 论元）**正好相反**。

```
　　@0 yy4.体　@1 po4.体　@0 => 1
　　　 雨　　　　 夜　　　 雨─饰弓→夜
```

### 14.2　为什么方向要相反

这不是随意定的。洄文认为：

- **填槽**是「谓语向外要论元」，所以箭头向外（谓语 → 论元）
- **限定**是「修饰语贴到被修饰者身上」，所以箭头向内（修饰语 → 被修饰者）

方向相反有个**很实用的后果**：汉语里会混的两种情况，在图上**不可能混**：

| 汉语 | 洄文 |
|---|---|
| 雨**的**夜（夜是雨的夜） | 雨 ─饰弓→ 夜 |
| 雨**落在**夜里（落的时间是夜） | 落 ─戊位→ 夜 |

一个是饰弓，一个是临弓；一个是「什么夜」，一个是「什么时候落」。
**在图上，这两句话长得完全不一样。**

### 14.3　饰弓能叠

一个词可以被多条饰弓限定：

```
　　@0 yy4.体　@1 po4.体　@2 ya2.貌　@0 => 1　@2 => 1
　　　 雨　　　　 夜　　　　 静　　　雨限定夜　静限定夜
　　→　雨中的、静的夜
```

### 14.4　练习

1. 「月之时」（月发生的时候）用哪种弓？（提示：`pe4` 月、`sy5` 派生语素「之时」）
2. `@0 ya2.貌　@1 po4.体　@0 => 1` 说的是什么？
3. 判断：「雨─饰弓→夜」和「落─戊位→夜」里的「夜」，作用一样吗？
4. 饰弓的箭头方向与临弓相比，是同向还是反向？

### 14.5　答案

1. **饰弓**（`=>`）：`@0 pe4.体　@1 sy5.体　@0 => 1`。但也常见用派生词直接合成。
2. 「静之夜」——静（当作性质）限定夜。
3. **不一样**。前者是「哪一种夜」，后者是「什么时候落」。
4. **反向**：临弓是谓语→论元，饰弓是修饰语→被修饰者。

## 第 15 课　换声：名词当动词使

### 15.1　一个词的五副面孔

同一个词，可以在句子里扮演五种立场，这叫**换声**：

| 换声 | 意思 | 记号（写在字外） |
|---|---|---|
| **体** | 指事物本身 | 不加 |
| **貌** | 指「……的」 | 正上方一点 |
| **用** | 指「做……」 | 正下方一竖 |
| **度** | 指「……地」 | 右侧双点 |
| **场** | 指「……之处／之时」 | 左侧一横 |

### 15.2　换声不造新词

`yy4.体`（雨）、`yy4.貌`（雨的）、`yy4.用`（下雨）、`yy4.度`（雨一般地）、
`yy4.场`（雨落之处）——**五个是同一个词**，音节一样、字形基底一样，
只是外面多了一个小记号。

### 15.3　换声之后，立场变了，意思没变

```
　　yy4.体　是「雨」这个东西
　　yy4.用　是「下雨」这件事
```

所以：

```
　　@0 yy4.用　@1 si6.体　@0 -甲-> 1　#see
　　　下雨　　　 我　　　 下雨，其主体是我
　　→　我看见（雨）落在我身上
```

「雨」本来是名词，换声为「用」之后就能接甲位了——**这就是「名词当动词使」**。

### 15.4　什么时候可以不写记号

如果**位置已经说明了一切**，记号可以省。比如 `@0 yy4.用　@1 si6.体　@0 -甲-> 1`
里的 `.用` 其实可以省，因为接甲位本身就说明它在当谓词用。

> 但对初学者，**建议写全**。写熟了自然知道哪里可以省。

### 15.5　练习

1. 「慢」要当「慢慢地」用，写哪一种换声？
2. `ye4.貌` 是什么意思？
3. 判断：`yy4.体` 与 `yy4.用` 是两个不同的词，所以词典里要收两条。
4. `pe2.用` 里的 `.用` 能不能省？为什么？

### 15.6　答案

1. **度**（`.度`，双点画在右侧）。
2. 「地的」——把「地」当性质来用。
3. **错**。它们是**同一个词**的五副面孔之一，词典只收一条（`yy4`），
   换声的用法写在条目里。
4. **可以省**。因为 `.用` 后面接了甲位，接甲位本身就说明它在当谓词——
   位置已经把立场交代清楚了。

## 第 16 课　义标：洄文不问你「真的假的」，只问「你怎么知道的」

### 16.1　一条硬规矩

**每一条陈述句，都必须带一个义标。** 漏了就是病句——
就像汉语里漏了主语、英语里漏了动词一样，是**语法错**，不是修辞问题。

### 16.2　八个义标

| 义标 | 源文写法 | 什么意思 |
|---|---|---|
| 亲见 | `#see` | 我亲眼看见的 |
| 亲闻 | `#hear` | 我亲耳听见的 |
| 亲身感受 | `#felt` | 我身上感到的（疼、饿、冷） |
| 推知 | `#infer` | 从痕迹推出来的（地上湿，推出下过雨） |
| 传闻 | `#hearsay` | 听别人说的 |
| 常识 | `#common` | 大家都知道的事 |
| 想象 | `#imagine` | 我设想、虚构的 |
| 梦 | `#dream` | 梦里见到的 |

**一句话只能带一个义标**（罩住整张图）。

### 16.3　为什么要有这条规矩

因为这门语言的世界观是：

> **它不区分「真话」与「假话」，只区分「你怎么知道的」。**

同一件事，用不同的义标说出来，**句子的合法性完全相同**，可信度不同：

```
　　@0 yy4.体　@1 pe2.用　@1 -甲-> 0　#see
　　　我看见雨落下来。

　　@0 yy4.体　@1 pe2.用　@1 -甲-> 0　#hearsay
　　　听说雨落下来。

　　@0 yy4.体　@1 pe2.用　@1 -甲-> 0　#imagine
　　　我设想雨落下来。
```

三句话语法上一模一样，都对。区别只在**你凭什么这么说**。

### 16.4　说错不算错，假称亲见才算错

- 你说「下雨了」（`#see`），结果没下 → 你**看错了**，不算说谎。
- 你听人说的，却标 `#see` → 你**假称自己看见了**，这在洄文里是**错**。

> 这是全书最值得记住的一条设计。语言可以不判真假，但必须交代来源。

### 16.5　练习

1. 说「我饿了」，用哪个义标？
2. 说「明天会下雨」，你并没有看见明天，用哪个义标？
3. 判断：漏掉义标的句子只是不够严谨，语法上没问题。
4. 你朋友告诉你他搬家了，你转述给别人，用哪个义标？

### 16.6　答案

1. **亲身感受**（`#felt`）——饿是自己身上感到的。
2. **推知**（`#infer`）或**传闻**（`#hearsay`），看你凭什么说。
   绝不能标 `#see`。
3. **错**。漏义标是**语法错**，句子不成立。
4. **传闻**（`#hearsay`）——除非你亲眼看见他搬家。

## 第 17 课　结际弓：因为、如果、虽然、于是

### 17.1　洄文没有连词

汉语的「因为、所以、虽然、但是、如果、于是」在洄文里**一个都没有**。
那么这些关系怎么表达？用**弓的记号**。

### 17.2　七个结际记号

| 记号 | 名 | 意思 |
|---|---|---|
| `<<` | **先** | 起点所说的发生在终点之先 |
| `>>` | **后** | 起点所说的发生在终点之后 |
| `+>` | **因** | 起点是终点的原因 |
| `?>` | **若** | 起点是终点的条件 |
| `<>` | **虽** | 起点是终点的让步（不构成反证） |
| `!>` | **目的** | 起点是终点所要达成的事 |
| `#>` | **于是** | 起点是终点的实际结果 |

**这些记号不读音。** 说话的时候靠停顿表达（弓内不停，弓间一小顿，结际弓一长顿）。
所以洄文**看着比听着精确**——它的正体是纸面。

### 17.3　结际弓连接的是「两张图」

这是结际弓与临弓、饰弓最大的不同：
**它的两端不是词，而是两张完整的图**。

```
　　[图一]　+>　[图二]
　　「下雨」这件事，是「我没去」的原因
```

源文里用方括号把子图括起来：

```
　　[ @0 yy4.体　@1 pe2.用　@1 -甲-> 0 ]　+>　@2
```

### 17.4　汉语对照

| 汉语 | 洄文 |
|---|---|
| 因为下雨，所以我没去 | [雨落] `+>` [我没去] |
| 如果下雨，我就不去 | [雨落] `?>` [我不去] |
| 虽然下雨，我还是去了 | [雨落] `<>` [我去了] |
| 下雨了，于是我没去 | [雨落] `#>` [我没去] |

注意「因为」和「于是」在洄文里是**两个不同的记号**（`+>` 与 `#>`）：
一个是「起因」，一个是「实际结果」。汉语里常常混用，洄文分得很清。

### 17.5　练习

1. 「因为下雨，路湿了」——用哪个记号？
2. 「如果明天下雨，比赛取消」——用哪个记号？
3. 判断：结际弓的记号要读出来。
4. 「虽然他说了，我还是不信」——用哪个记号？

### 17.6　答案

1. `+>`（因）。
2. `?>`（若）。
3. **错**。这些记号**不读音**，靠停顿表达。
4. `<>`（虽）——让步。

## 第 18 课　子图：一句话里套一句话

### 18.1　子图是什么

**一张图可以当成另一张图的一个端点。** 这就是洄文的「从句」。

前面第 17 课的结际弓，两端就是子图。子图还有别的用法：
**当作临位里的一个论元**。

### 18.2　子图当论元

```
　　@3 po3.用　　　　　答
　　@4 soe6.体　　　　 他
　　@3 -甲-> 4　　　　 答，其主体是他
　　[ @10 yy4.体　@11 pe2.用　@11 -甲-> 10 ]　-庚->　@3
　　　　（子图：雨落）——整体当作「答」的庚位（内容）
```

说的是：**他回答「雨落」**。注意整张子图（雨落）被当成一个整体，
填进了「答」的庚位。

### 18.3　为什么要用子图

因为洄文的图**不能有圈**（第 11 课）。那么「他说他要来」这种一层套一层的句子怎么办？
答案是：**把内层做成一张独立的子图，再把整张子图当作外层的一个端点**。

这也解释了洄文的一句话为什么可以很长——不是线性地排下去，
而是**图里套图**。

### 18.4　回指弓：要指「自己」怎么办

图上不能画圈，那「我自己」怎么说？用**回指弓**：指向已经出现过的那个结。

```
　　@0 si6.体　　　　我
　　@1 gy2.用　　　　回忆
　　@1 -甲-> 0　　　 回忆，其主体是我
　　@1 -庚-> 0..　　 回忆，其内容也是「我」（回指上面那个结）
```

`0..` 里的 `..` 就是回指的记号，读作「前面那个 0」。

回指在各处都管用：谈「自己」「同一个」「刚才说的那个」，全用它。

### 18.5　练习

1. 「他说雨落」怎么写？（`pe3` 言说，槽表 甲庚）
2. 回指弓和普通的临弓有什么不同？
3. 为什么洄文需要子图？（提示：想想图不能有圈这条规矩）
4. 判断：一张子图里可以再套一张子图。

### 18.6　答案

1. ```
　　@0 pe3.用　@1 soe6.体　@0 -甲-> 1
　　[ @2 yy4.体　@3 pe2.用　@3 -甲-> 2 ]　-庚->　@0
　　#hearsay
　　```
2. 回指弓指向**已经出现过的结**，图上是虚线；临弓指向新填进来的论元。
   回指用来避免画圈。
3. 因为图不能有圈。要把「话里的话」表示出来，只能把内层做成一张独立的子图，
   再把整张子图当端点。
4. **对**。子图里可以再嵌套子图，源文里就是方括号套方括号。

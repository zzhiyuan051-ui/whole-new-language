# 第一编　认识洄文

---

## 第 1 课　洄文是什么：一张图，不是一串词

### 1.1　先说汉语

汉语说「我吃饭」，是**三个词排成一队**：

```
我　→　吃　→　饭
```

谁在前、谁在后，意思就不同。「我吃饭」和「饭吃我」是两回事。
所以汉语是**线性的**：词像珠子串在一根线上。

### 1.2　洄文不是这样

洄文说同一件事，是**画一张图**：先摆三个点，再画两条线。

```
　　　　　　〔我〕
　　　　　　　│
　　　　　　　│　甲位（谁在做）
　　　　　　　▼
　　　　　　〔吃〕
　　　　　　　│
　　　　　　　│　乙位（做的什么）
　　　　　　　▼
　　　　　　〔饭〕
```

- 图上的点叫「**结**」。一个结就是一个词。
- 点与点之间的线叫「**弓**」。弓有方向，箭头指向被填进去的那个词。
- **箭头的方向很要紧**：`吃 → 我` 的意思是「吃这件事，做的人是我」。
  箭头是从**动作**画向**做动作的人**，不是反过来。

### 1.3　为什么要把语言做成图

因为线性排列有个天生的毛病：**顺序是唯一的线索**。
汉语里「咬死了猎人的狗」有歧义，就是顺序不够用。

洄文把关系**画出来**，歧义就少：谁连谁，一眼看见。
代价是——**纸面上的位置变成了语法的一部分**。同一个词摆在不同的位置，
就是不同的句子。这一点你后面会越来越有体会。

### 1.4　一句话里的三类东西

洄文的一句话里，只有三类东西：

| 类 | 是什么 | 例子 |
|---|---|---|
| **结** | 词，图上的点 | 「我」「吃」「饭」 |
| **弓** | 关系，图上的线 | 吃─甲位→我 |
| **标记** | 交代说话人立场的符号 | 义标（见第 16 课） |

汉语里的「因为、所以、虽然、但是、如果」在洄文里**不是词**，
而是**弓自己的形状**（第 17 课）。这是洄文省掉的一整类词。

### 1.5　练习

1. 用一句话说出「洄文和汉语最大的不同是什么」。
2. 下面这张图说的是什么事？谁在做，做的什么？

```
　　　　　　〔我〕
　　　　　　　▲
　　　　　　　│　甲位
　　　　　　〔看〕
　　　　　　　▲
　　　　　　　│　乙位
　　　　　　〔月〕
```

3. 猜一猜：如果要把「我看见月亮」改成「月亮看见我」，这张图要动哪几处？

### 1.6　答案

1. 参考：汉语靠**词的排列顺序**表达关系；洄文靠**点与点之间的连线**表达关系，
   一句话是一张有方向的图。
2. 说的事是「**我看月**」——`看`是中心，`我`填进甲位（谁在看），`月`填进乙位（看的什么）。
3. 要把两条箭头都反过来：`看 ─甲位→ 月`、`看 ─乙位→ 我`。
   **注意：词一个都没换，只是箭头换了方向**——这就是「位置与连线就是语法」。

## 第 2 课　洄文和汉语差在哪：六条对照

学一门新语言，最省力的办法是**先知道它哪里跟母语不一样**。
下面六条是洄文与汉语最主要的分岔，先记住结论，后面每一课都会展开。

### 2.1　词不分词性

汉语里「书」是名词，「看」是动词，词典上标好了。
洄文**不标词性**——一个词是什么身份，看**它怎么接**：

```
　看　接甲位（谁看）与乙位（看什么）　→　当动词用
　看　被饰弓限定（什么样的看）　　　　→　当名词用
```

这叫「**换声**」（第 15 课）。所以洄文的词典条目上写的是「**槽表**」
（这个词要接几个位），而不是「名词／动词」。

### 2.2　没有主语、谓语、宾语

汉语语法讲「主谓宾」。洄文讲**七临位**（第 12 课）：

| 位 | 名 | 汉语大致对应 |
|---|---|---|
| **甲** | 施事 | 谁在做 |
| **乙** | 受事 | 做的是什么 |
| **丙** | 予事 | 给谁、对谁 |
| **丁** | 工具 | 用什么 |
| **戊** | 处所／时间 | 在哪里、什么时候 |
| **己** | 因由 | 因为什么、往哪里 |
| **庚** | 语题 | 说了什么、想了什么 |

「主谓宾」只是这七位里最常用的三位（甲、乙，加上中心词），**不是句子的骨架**。

### 2.3　没有连词

汉语的「因为、所以、虽然、但是、如果、于是」在洄文里**不存在**。
关系由**弓的记号**承担：

```
　<<　先　　　>>　后　　　+>　因
　?>　若　　　<>　虽　　　!>　目的　　　#>　于是
```

这些记号**不读音**（第 17 课）。所以洄文的口语比书面语含糊——
这门语言的正体是**纸面**。

### 2.4　真假不由语法标记，信息来源才由语法标记

汉语说「下雨了」，不问你怎么知道的。
洄文里，**每条陈述句都必须带一个「义标」**，写明信息来源：

```
　亲见　亲闻　亲身感受　推知　传闻　常识　想象　梦
```

漏了义标，就像汉语里漏了主语一样，是**病句**（第 16 课）。
这条规矩出自这门语言的世界观：**它不区分真话假话，只区分你怎么知道的**。
说错不算错，**假称自己亲眼看见**才算错。

### 2.5　字不表音

汉字「雨」读 yǔ，字形里还留着一点声音的线索（形声字）。
洄文的字形**完全不表音**——看到字，你念不出来；听到音，你写不出来。
两条通路各走各的，只在词表里相遇。

这听起来别扭，但有个好处：**字形可以做得很规整**。
洄文的每个字都是「算」出来的，不是一个个造出来的（第 7 课）。

### 2.6　能算出来的词不另立

汉语有「雨伞」「雨衣」「雨鞋」，每一个都要单独学。
洄文里这些**不另立词条**，而是用**派生式**算出来：

```
　雨　＋　{X}具　＝　雨具　（用于雨的器具）
```

所以洄文的词表有边界，但**表达力靠组合**。
你学会 20 个派生式，就等于学会了 2488 个词（第 15 课、词法规范）。

### 2.7　一张对照表

| | 汉语 | 洄文 |
|---|---|---|
| 句子的样子 | 词排成一队 | 一张有方向的图 |
| 关系靠什么 | 语序 | 连线（弓）的方向与记号 |
| 词有词性吗 | 有（名/动/形…） | 没有（看接法） |
| 句子的骨架 | 主谓宾 | 七临位 |
| 连词 | 因为/所以/如果… | 不存在（是弓的形状） |
| 真假 | 一般不标记 | 不标记真假，**必标信息来源** |
| 字 | 表意，部分表音 | **完全不表音** |
| 新词 | 可以随便造 | 只有两条路：派生、图上复合 |

### 2.8　练习

1. 汉语「因为下雨，所以我没去」——在洄文里，「因为」要用什么表示？
2. 洄文的词典条目为什么不标「名词／动词」，而标「槽表」？
3. 判断对错：洄文里「我打你」和「你打我」，只要把词换个位置就能表达。
4. 洄文里说「昨天下雨了」，除了「昨天」「雨」「下」，还必须写什么？

### 2.9　答案

1. 用**结际弓的记号** `+>`（因）。它不是一个词，是两张子图之间那条线的形状。
2. 因为洄文的词**没有固定词性**，同一个词换个接法就换一种身份，
   所以要知道怎么用它，得知道它需要接哪几个位（槽表）。
3. **错**。要把箭头方向反过来，而不是把词换个位置。换位置在洄文里不改变关系。
4. 必须写**义标**——是你亲眼看见的（`#see`），还是听人说的（`#hearsay`），
   还是推出来的（`#infer`）。漏了就是病句。

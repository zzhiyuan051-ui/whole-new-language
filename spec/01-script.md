# 洄文 · 文字学规范（wén · 符号系统）

> 本文件定义洄文的**书写符号系统**。所有字形由一个函数生成：`字形 = 纹(i)`。
> 词表（`lexicon.tsv`）里的 `glyph_index` 列就是 `i`；任何工具都能由 `i` 独立重算出字形，
> 不需要抄字形图。这是「自源文字」，不是任何既有文字的变形。

---

## 0. 七条元规则

| # | 规则 | 后果 |
|---|------|------|
| 1 | **形自释**：字形自身编码词根的编号与场属，不看词表也能复原 | 文字是**算法**，不是约定俗成的码表 |
| 2 | **形声二分**：字形与读音**没有**任何对应关系 | 同音不同形、同形不同音都合法；书写不表音 |
| 3 | **部件组合**：字形由固定笔画部件在固定区位拼合而成 | 无需数千个独立字符，字库由**位 × 值**生成 |
| 4 | **一形一义**：一个字形只表示一个词根（无多义字） | 义项分裂必须造新字——抑制歧义 |
| 5 | **层级继承**：换声字（性/貌/体/态）必须在基底字形上留痕 | 一个词族在纸面上必然长得像 |
| 6 | **空间参与语法**：页面上字的位置本身承担句法信息 | 书写不是记录语言的容器，而是语法的一部分 |
| 7 | **无错字，只有难读字**：笔画写潦草不失义，写完区位才算完 | 书法与正字法的边界不同于汉文 |

## 1. 笔画（rat·基元）

**16 个基元**，分四族。所有字形只由它们拼成。

| 族 | 名 | 形 | ASCII 记法 | 笔画数 |
|---|---|---|---|---|
| **点族** | 点 | · | `.` | 1 |
| | 双点 | ∶ | `:` | 2 |
| | 三点 | ∴ | `:.` | 3 |
| | 四点 | ∷ | `::` | 4 |
| **线族** | 短横 | – | `-` | 1 |
| | 双横 | = | `=` | 2 |
| | 三横 | ≡ | `≡` | 3 |
| | 竖 | ｜ | `\|` | 1 |
| **折族** | 折 | ⌐ | `r` | 2 |
| | 双折 | ⌐⌐ | `rr` | 4 |
| | 角 | ∟ | `L` | 2 |

> 「笔画数」是**重写规则**用的：手写体允许连笔，但笔画数守恒（见 §6）。

## 2. 区位（kw·字格）

字形占据一个 **4 列 × 5 行** 的字格。中央格（第 3 列第 3 行）**永远留给语义类标记**，
其余 **12 格**为数字位。

```
┌──────┬──────┬──────┬──────┐
│ 位1  │ 位2  │ 位11 │ 位3  │   ← 位11 预留
├──────┼──────┼──────┼──────┤
│      │ 位7  │      │ 位8  │   ← 位7/位8 第一次启用
├──────┼──────┼──────┼──────┤
│ 位9  │      │ 类标 │      │   ← 位9 预留；中央格 = 语义类
├──────┼──────┼──────┼──────┤
│      │ 位10 │ 位12 │      │   ← 位10/位12 预留
├──────┼──────┼──────┼──────┤
│ 位6  │ 位5  │      │ 位4  │
└──────┴──────┴──────┴──────┘
```

**本次定稿使用 8 位**（够 4⁸ = **65536** 个字形），另 4 位（位9–位12）**用作家族纹**
（见 §4.5：这四位是后加的第四个视觉维度，用来把近形字分开）。

| 位号 | 位置 | 权（4 的幂） | 状态 |
|---|---|---|---|
| 位1 | 左上 | 4⁷ = 16384 | 使用（双笔） |
| 位2 | 上中左 | 4⁶ = 4096 | 使用（双笔） |
| 位3 | 右上 | 4⁵ = 1024 | 使用 |
| 位4 | 右下 | 4⁴ = 256 | 使用 |
| 位5 | 下中 | 4³ = 64 | 使用 |
| 位6 | 左下 | 4² = 16 | 使用 |
| 位7 | 上中右 | 4¹ = 4 | 使用（第一次启用预留位） |
| 位8 | 右中 | 4⁰ = 1 | 使用（第一次启用预留位） |
| 位9 | 左中 | — | **家族纹**（见 §4.5） |
| 位10 | 下中左 | — | **家族纹** |
| 位11 | 上中 | — | **家族纹** |
| 位12 | 中下 | — | **家族纹** |

> 位1 与位2 的笔画用**双笔**（双点／双横／双环），以此在视觉上压住字形的重心。

## 3. 数字位取值：0 → 3

每个数字位取 0、1、2、3 之一，对应一种笔画：

| 值 | 笔画 | ASCII | 视觉 |
|---|---|---|---|
| **0** | 空 | `0` | 不落笔（留白） |
| **1** | 点 | `1` | 单点（位1/位2 写作双点） |
| **2** | 横 | `2` | 单横（角位写作斜线；位1/位2 写作双横） |
| **3** | 环 | `3` | 小环（位1/位2 写作双环） |

**位1 / 位2 的双笔规则**（其余六位一律单笔）：

| 位 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 位1（左上，权重最大） | 空 | ∶ 双点 | = 双横 | ◎ 双环 |
| 位2（上中左） | 空 | ∶ 双点 | = 双横 | ◎ 双环 |
| 位3–位8 | 空 | · 点 | – 横／／ ＼ 斜 | ○ 环 |

于是 **`i` → 字形** 是唯一确定的：

```
i = 137  →  137 = 2·64 + 1·4 + 1·1   （高位补零）
         位1=0(空) 位2=0(空) 位3=0(空) 位4=0(空) 位5=2(横) 位6=0(空)
         位7=1(点) 位8=1(点)
```

## 4. 边框（校验纹）与中央格（类标记）

字形把两件事**分成两套互不干扰的机制**：

| | 由什么决定 | 能校验吗 | 作用 |
|---|---|---|---|
| **八个数字位 + 边框** | 编号 `i` | **能**（边框 = i mod 3） | 定位一个唯一编号 |
| **中央格的内点式** | 语义类 | 不能（是分类，不是数值） | 一眼读出一个字属于哪一类 |

### 4.1 边框是可心算的校验

```
边框纹 = ( 位1 + 位2 + 位3 + 位4 + 位5 + 位6 + 位7 + 位8 )  mod  3
```

> **为什么成立**：编号是基-4 的，而 `4 ≡ 1 (mod 3)`，所以 `4^k ≡ 1 (mod 3)`，
> 于是 `i = Σ dₖ·4ᵏ ≡ Σ dₖ (mod 3)`。
> 八个一位数相加（和最大 24），看是不是 3 的倍数 —— **这是能心算的校验**。
> 换句话说：**边框纹 ≡ 编号 i (mod 3)**。

**抄错一位笔画，边框就对不上**。而边框本身不可能抄错——它写在字的最外围，
且是数字位的导数。三者（数字位、边框、编号）互相钉死。

### 4.2 中央格是分类，不是数值

中央格写**语义类**的标记（见 §4.3）。它与编号**没有算术关系**——
这是刻意的：**校验**要能算，**分类**要一眼看。把两者混成一个机制，
结果是既算不快、也看不清。

> **一处实施细节**：字表里 `编号 mod 44 == 类号`（44 = 语义类总数）。
> 这是为了让「编号」与「类」在同一个数上对齐，便于索引与排字；
> 但这不是必须的——两者的**语义**仍然独立，编号改了类不必跟着改。

### 4.3 44 个语义类（20 式标记）
**44 个语义类**，由 **20 式中央标记**循环承载：类号 `k` 用标记 `k mod 20`。
同标记的两类分属不同大族（如「本体」与「医药」），配合边框与数位仍可区分。

| 类号 | 类名 | 标记 | 类号 | 类名 | 标记 |
|---:|---|---|---:|---|---|
| 0 | 本体 | · 单点 | 22 | 军事 | 三点 |
| 1 | 数量 | ∶ 双点 | 23 | 农事 | 四点 |
| 2 | 空间 | ∴ 三点 | 24 | 器用 | 单环 |
| 3 | 时间 | ∷ 四点 | 25 | 游艺 | 双环 |
| 4 | 运动 | ○ 单环 | 26 | 天候 | 药丸 |
| 5 | 身体 | ◎ 双环 | 27 | 禽兽 | 尖角 |
| 6 | 心灵 | ▭ 药丸 | 28 | 草木 | 三叉 |
| 7 | 社会 | ⌃ 尖角 | 29 | 形质 | 三角框 |
| 8 | 经济 | Y 三叉 | 30 | 物质 | 粗横 |
| 9 | 信息 | △ 三角框 | 31 | 天文 | 叉 |
| 10 | 美感 | ▬ 粗横 | 32 | 地理 | 人字 |
| 11 | 伦理 | ✕ 叉 | 33 | 乐律 | 双弧 |

> 或把标记做成复合式（两个标记并置）。旧字因此**永远不用改**。
> 这是把「编号位」与「类标记」分成两套独立机制换来的好处。

## 4.5　家族纹（辨识度维度）：为什么必须加，以及怎么加

### 问题（实测，不是估计）

字形原本只有 **3 种边框 × 20 种中央标记 = 60 种骨架**，3000 个词挤在里面
（每个骨架平均 50 个词，最多 59 个）。用「几个位的取值不同」当距离来量：

| 档 | 修复前 | 说明 |
|---|---|---|
| 相差 ≤2 位 | **6593 对 → 每词摊 4.4 个** | 最容易混 |
| 相差 ≤3 位 | **16661 对 → 每词摊 11.1 个** | |

最难分的恰恰是**核心抽象词**：`现实 / 果 / 同 / 真 / 必然 / 状态`
全都落在「边框 0 + 标记 0」这一个骨架上，差别只是几个点的位置。

**根源**：字形算法优化的三项（唯一性、可校验、可扩充）对人类都是**免费奉送**的，
真正值钱的**视觉区分度没有人买单**。

### 解法：把四个预留格变成第四个视觉维度

字格的**四角原本是预留格（位9–位12）**。现在用它们画一个「**家族纹**」：

| 家族 | 纹样 | 画法 |
|---:|---|---|
| 0 | 空角 | 四角不落笔 |
| 1 | 点角 | 四角各一点 |
| 2 | 双点角 | 四角各一双点 |
| 3 | 环角 | 四角各一小环 |
| 4 | 横角 | 四角各一短横 |
| 5 | 方角 | 四角各一小方框 |
| 6 | 叉角 | 四角各一叉 |
| 7 | 角角 | 四角各一三角 |

于是可辨外形从 `3 × 20 = 60` 升到 `3 × 20 × 8 = **480**`。

### 关键：家族号怎么定（这一步决定成败）

**不能**按编号顺序轮流发号——编号在视觉上并不连续，轮流发号会把长得像的
两个字一起塞进同一家族。实测那只能把 4.4 降到 2.9（降 34%）。

正确做法是**贪心**：把所有字按「骨架 → 数位模式」排序，
每个字放进「**与已有成员最不像**」的那个家族（同时用平衡约束防止某家族被塞满）。
这样直接优化目标本身：

| 档 | 修复前 | 修复后 | 降幅 |
|---|---|---|---|
| 相差 ≤2 位 | 4.4 个/词 | **0.5 个/词** | 77% |
| 相差 ≤3 位 | 11.1 个/词 | **1.4 个/词** | 87% |

核心抽象词现在分到了不同家族：现实 0／果 3／状态 5／同 7／真 7／必然 1——
**四角纹不同，一眼可分**。

> 这条指标已进自检（阈值：≤2 笔 ≤1.0 个/词）。字形辨识度从此是**可验收的工程指标**，
> 不是审美问题。

## 5. 换声（fān šēn）：词族在纸面的痕迹

洄文词根可以**换声**（性与貌的转换）。换声不造新字，而是给基底字形加**记号**——
记号加在字格**外侧**（字的外围四个方位），故不干扰数字位与类标记。

| 声 | 语法功能 | 记号 | 位置 | ASCII |
|---|---|---|---|---|
| **体** | 名词性（事物） | 无记号 | — | （默认） |
| **貌** | 形容词性（性质） | 单点 | 正上方 | `^` |
| **用** | 动词性（动作/关系） | 单竖 | 正下方 | `v` |
| **度** | 副词性（程度/方式） | 双点 | 右侧 | `>` |
| **场** | 处所/时间（状语） | 短横 | 左侧 | `<` |

例：`◇ 系` 的字加下竖就是动词，加右双点就是副词：

```
    ·            ·            ·
  ┌───┐        ┌───┐        ┌───┐ ∶
  │◇ ·│        │◇ ·│        │◇ ·│
  └───┘        └───┘        └───┘
    │  ← 用      （体）        （度）
```

**记号是可省的**：上下文明确时（尤其在关系图里，结的位置已经说明它扮演什么），
写手可以只写基底字形。省记号不会造成歧义，因为**结的位置是冗余的**。

## 6. 三种字体（同一字形的三副面孔）

| 字体 | 用途 | 与正体的关系 |
|---|---|---|
| **正体**（正笔） | 碑刻、印刷、字表 | 严格字格 |
| **行体**（连笔） | 日常书写、信件 | 允许连笔，**笔画数守恒**、区位不移 |
| **简笔**（速记） | 速记、私人笔记 | 只写位1+位2（粗粒度），类标记必写 |
| **刻体**（kè） | 器物铭刻 | 直笔化：环→方，斜→竖横 |

> 判据：一个字形是否「写对」，看**位值序列**与**边框**是否一致，不看笔画是否工整。
> 潦草不失义，这是刻意的——因为信息在**结构与位置**里，不在笔锋里。

## 7. 页面上的字形（空间参与语法）

页面上字形的**位置**承担句法信息。三条空间规则：

1. **关系图**：一句的诸字形按关系图布置；有关系的两个字形之间画**关系线**（§语法）。
   页面不是线性的，读者沿关系线走，不沿行读。
2. **读序**：若必须线性读出（吟诵、写信封、转写成别的文字），用**读序线**——
   从首结起，沿关系线走一条不重复的路径并编号（小圈数字：①②③…）。
3. **段落**：段落由**退场线**（一段横线）分隔；引语用**缩进的双竖线**围起；
   对话的说话人写在引语块的左上角。

> 因此洄文的「排版」不是美观问题，而是**语法的一部分**：同样的字，位置不同，句意不同。

## 8. 与既有文字的关系

| 对比项 | 洄文 | 汉文 | 韩文 | 拉丁 |
|---|---|---|---|---|
| 基本单位 | 坐标位（非笔画、非字母） | 笔画/部首 | 字母/音节块 | 字母 |
| 表音 | **完全不表音** | 形声字部分表音 | 完全表音 | 完全表音 |
| 查字 | 按位值序列（= 编号） | 部首/笔画/拼音 | 字母序 | 字母序 |
| 扩充 | 加位 / 改模数 | 造新字 | 造新字母 | 造新词 |
| 冗余 | **边框 = 位值和的模 3**（自校验） | 无 | 无 | 无 |
| 语法参与 | **是**（位置即句法） | 否 | 否 | 否 |

**洄文不是任何文字的转写方案**：它的字形不表示音，音节不表示形，两者只在一个地方相遇
——词表。这是刻意的：一条信息可以只用眼睛传达，也可以只用耳朵传达，两条通路不必同构。

# 洄文 · 语法规范（luò · 图语法）

> 本文件定义洄文的**语法逻辑**。它不是「主谓宾」的变体，也不是任何自然语言的重新排词。
> 一句话在洄文里是一个**有向图**：词根是结（node），关系是弓（arc）。
> 说一句话 = 搭一张图；听懂一句话 = 在图上走通。

---

## 0. 与自然语言的分岔点

| | 自然语言（含汉语/英语） | 洄文 |
|---|---|---|
| 基本单位 | 词，按**线性**排列 | 结（词根）+ 弓（关系），成**图** |
| 句法信息在哪 | 位置与虚词 | **弓的形状与标记**；页面位置 |
| 一个词的身份 | 名词/动词是词库属性 | **临位**（valence）：词根自带若干待填的槽 |
| 「主谓宾」 | 是句子的骨架 | **不存在**——只是七种临位里最常用的三种 |
| 修饰 | 定语从句/介词短语 | 弓的**起点**贴在宿主上（不换行、不嵌套从句） |
| 递归 | 从句嵌套 | 弓的**终点可以是另一张图** |
| 真假与语气 | 语气词 | 中央的**模态圈**，罩住整张图 |
| 说话人立场 | 少数语言有 | **义标**`⊢`：每一句必标信息来源的**种类** |

**七条设计律**（任何合法句都必须满足，工具会检查）：

1. **结必有根**：每个结绑定一个词根，不得凭空结。
2. **弓必双向**：每条弓有且只有一个起点结与一个终点结。
3. **临位必满**：词根的必填临位槽全都接上弓之后，句子才闭合。
4. **单主**：一张图里有且只有一个**主结**（首结），其余结都沿弓可达。
5. **禁环**：线性书写时弓只能接在**已存在的结**上（图论上即无环）。递归靠弓终点指向子图实现。
6. **义标必具**：无义标的句子是未完成的句子（见 §6）。
7. **模态唯一**：一张图最多一个模态圈。

## 1. 结与位

### 1.1 词根（结）

词根是**不自由语素**：它不能单独成句，必须进入至少一条弓。词根在句中的身份由**临位**决定，
不由词库固定。同一个词根换一种接法，就换一种词性——**洄文没有词类，只有接法**。

### 1.2 七临位（lín · 论元角色）

| 位 | 名 | 含义 | 典型汉语对应 | 弓形 |
|---|---|---|---|---|
| **甲** | 施事/主体 | 动作或状态的主体 | 「谁」在做事 / 谁是这样 | 起端实心箭尾 |
| **乙** | 受事/客体 | 被作用、被指向者 | 「把谁/什么」 | 起端空心箭尾 |
| **丙** | 予事/受益 | 接受者、受益者、受损者 | 「给谁 / 对谁」 | 双箭头 |
| **丁** | 工具/手段 | 借以完成的物或方法 | 「用什么」 | 带点的实心尾 |
| **戊** | 处所/时间 | 发生的位置与时段 | 「在哪里 / 何时」 | 短横尾（贴地） |
| **己** | 因/由 | 原因、来源、依据 | 「因为 / 据」 | 折线尾 |
| **庚** | 语/题 | 言说或思考的内容 | 「说了什么 / 关于」 | 双线尾 |

> **这七位不是格标记，是槽位。** 每个词根自带一张「槽表」（valence frame），写明
> 它需要哪些位。例如「给」类词根是 `甲丙乙`（谁给、给谁、给什么），
> 「睡」类词根是 `甲戊`（谁睡、在哪/何时），「真」类词根是 `乙`（什么是真的）。
> **接不满槽，句子不闭合；多接的槽不算错，算「附带说明」**（用虚线弓表示）。

### 1.3 槽表从哪来

槽表**不需要逐个背**，它由词根的**意义类型**系统派生（`tools/valence.py` 实现）：

| 词根的意义类型 | 槽表 | 例 |
|---|---|---|
| 事物（n） | `乙` | 实体、雨、手 |
| 动作（v） | `甲乙` | 打、走、说 |
| 给予/传递（v，含"与、送、教"义） | `甲丙乙` | 给、送、教 |
| 状态/性质（a） | `乙` | 冷、真、远 |
| 度量/程度（d） | `乙` | 很、略、最 |
| 感知/心理（v） | `甲庚` | 想、怕、知道 |
| 位移（v） | `甲戊己` | 走、来、去 |

**这是推导，不是规定**：词表里凡是标了 `v` 的都是 `甲乙`，标了 `a` 的都是 `乙`；
用户可在项目里显式覆写某词的槽表（`tools/valence.py --override`）。

## 2. 弓（关系）

### 2.1 弓的两段

每条弓分两段，写法上**先写起点、再写终点**：

```
起点结  ◀─记号─  终点结
```

### 2.2 三种弓

| 弓 | 记号（ASCII） | 图上的意思 | 一句话说清 |
|---|---|---|---|
| **临弓** | `->` | 把终点结填进起点结的一个临位槽 | 补足论元 |
| **饰弓** | `=>` | 终点结**修饰**起点结（缩小其外延/加限定） | 定语、状语、同位语 |
| **结际弓** | `<记>=>` | 两个**已闭合的子图**之间的关系 | 因果、时序、条件、言说嵌套 |

> **方向至关重要**：`临弓`从**谓语流向论元**（谓语是起点）；`饰弓`从**修饰语流向被修饰者**
> （修饰语是起点）。两种方向相反，因为洄文认为「限定」的施力方向与「填槽」相反。
> 这不是随意的：它让「雨的夜里」与「夜里下雨」在图上**不可能混同**。

### 2.3 结际弓的五种记号

| 记号 | 关系 | 语义 |
|---|---|---|
| `<<` | **先** | 起点所指之事发生在终点之先 |
| `>>` | **后** | 起点所指之事发生在终点之后 |
| `+>` | **因** | 起点是终点的原因/理由 |
| `?>` | **若** | 起点是终点的条件（充分） |
| `<>` | **虽** | 起点是终点的让步（不构成反证） |

另有**目的** `!>`（起点是终点所要达成的事）与**于是** `|>`（起点是终点的实际结果）。

### 2.4 弓的端点可以是子图

这是递归所在。线性写法用方括号把已闭合的子图括起来，再当端点用：

```
[ ya >> yi ]  +>  poe
```

读作：「既已存在，又在此处」这件事，是「真」的原因。
（`ya` 存在、`yi` 在此 —— 括号内是一张完整的子图，整体充当外层的起点结。）

## 3. 线性书写（lo · 读序形式）

线性形式是给**机器、吟诵、转写**用的。它不是洄文的正体——正体是纸上的图。
但线性形式是可逆的：`tools/hwparse.py` 能把它解析回图，`tools/hwrender.py` 能把图重画成纸面。

### 3.1 结的声明

```
@<标号> <词根>[.<换声>]
```

- 标号：`0-9`、`a-z`，或任意标识符。
- 换声后缀：`.体`（默认，可省）`.貌`（形容词性）`.用`（动词性）`.度`（副词性）`.场`（状语）
  也可写 `@n` `@a` `@v` `@d` `@l` 这套拉丁缩写。

### 3.2 例

```
@0 雨.体            @1 下.用
@2 夜.体            @3 冷.貌
@0 -> 1             // 雨（是）下（的施事？）——见下注
...
```

**完整可运行例（「雨下在冷夜里」）**：

```
@0 u.体            // 雨
@1 b.用            // 下（降）
@2 i.体            // 夜
@3 a.貌            // 冷
@1 -> 0            // 下，其主体是「雨」        （甲位）
@3 => 2            // 冷，修饰「夜」            （饰弓）
@1 -> 2            // 下，其处所/时段是「夜」    （戊位，由槽表指派）
```

> **临位怎么知道是哪一位？** 由槽表顺序指派：`@1`（动作类）槽表为 `甲乙`，
> 第一条临弓填甲、第二条填乙；若还要接处所，写显式位名：`@1 -戊-> 2`。
> 因此**默认按槽序**，需要指定时用 `-甲->` `-乙->` … 这种显式形式。

### 3.3 模态与否定

```
?  ya        疑问（罩住整图或某结）
~  poe       否定（作用在最近的一条弓或一个结上）
!  ...       祈使
```

写在图的最前面（罩住全图）或紧贴在某个结前（只作用那一结）。

### 3.4 义标（必具）

每条**陈述句**必须带一个义标，写明信息来源的种类：

| 义标 | ASCII | 含义 |
|---|---|---|
| **亲见** | `#see` | 说话人亲眼所见 |
| **亲闻** | `#hear` | 亲耳所闻 |
| **亲历** | `#felt` | 亲身感受（痛、饿、冷） |
| **推知** | `#infer` | 由痕迹推断 |
| **传闻** | `#hearsay` | 听别人说 |
| **常识** | `#common` | 公认之事 |
| **想象** | `#imagine` | 虚构、设想 |
| **梦** | `#dream` | 梦中 |

> 义标是**语法成分**，不是修辞。缺义标的句子在洄文里等同于汉语里缺主语的病句。
> 这条规则出自这门语言的世界观：**洄文不区分「真」与「假」，只区分「你怎么知道的」**。
> 说错话不算错，**假称自己看见**才是错。

## 4. 换声（词类转换）

词根可加换声记号改变它在句中的**立场**，但不改变它的槽表之外的词义：

| 换声 | 效果 | 例 |
|---|---|---|
| `.体` | 指事物本身 | `a.体` = 冷（作为一种东西） |
| `.貌` | 指具有该性质者 | `a.貌` = 冷的 |
| `.用` | 指该动作/关系 | `a.用` = 变冷 |
| `.度` | 指程度/方式 | `a.度` = 冷地 |
| `.场` | 指该事发生之处/时 | `a.场` = 冷处/冷时 |

**换声不是构词，是投影**：它把同一个词根投影到句子的不同位置上，纸面上留痕（见文字学 §5）。

## 5. 复指与照应（húi · 回指）

图上重提一个结，用**回指弓**（`..`）：

```
@4 人.体
@5 想.用
@5 -> 4          甲
@5 -> 2..        庚（想的对象，回指上面那个「夜」）
```

回指弓指向**已出现过的结**，图上画成虚线。这解决了「图不能成环」带来的表达局限：
要谈「自己」，就用回指，而不是自环。

## 6. 句与篇

- **句**（lo）：一张闭合的图。闭合条件 = 临位全满 + 单主 + 义标具备。
- **段**（sòn）：若干句共享一个话题结。第一句的主结即该段**话题**，后续句可用回指弓挂上。
- **篇**（li）：若干段。段与段之间用**结际弓**相连（故事里的「于是」「然而」都是结际弓）。

> 洄文没有「连词」这一类词——连接由**弓**完成。这是它在语法上最省的地方：
> 汉语要用「因为/所以/虽然/但是/于是/如果」六个词做的事，洄文只用**五个记号**，
> 而且这五个记号不占词表、不进句子、不出现在读音里（它们是**关系本身的形状**）。

---

## 7. 读音形式

线性形式**可读**，但读音是**派生**的，不是原生的：

1. 读一段从主结起，沿临弓按槽序、再沿饰弓读修饰语。
2. 每个结读成一个音节（词根音节 + 换声的声调变化）。
3. 弓的记号**不读音**——关系由**语序与停顿**表达：
   弓内无停顿，弓间一短顿，结际弓一长顿。
4. 义标读成句末的一个轻声音节（`#see` → `sa`、`#hearsay` → `za` 等，见词表「虚词」节）。

> 结论：洄文**看着比听着更精确**。这是刻意的取舍——它的正体是纸面。
